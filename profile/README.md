# Registrai

Registrai publishes sourced, dated data on the Arc ecosystem for people and AI agents.

- [builder.registrai.cc](https://builder.registrai.cc): the site
- [Arc ecosystem directory](https://builder.registrai.cc/ecosystem/): projects building on or announced for Arc, each with status, evidence and sources
- [Arc in numbers](https://builder.registrai.cc/arc/): chain and stablecoin figures with daily snapshots
- [Methodology](https://builder.registrai.cc/methodology/): definitions, sources and limits
- [arc-ecosystem](https://github.com/registrai-multichain/arc-ecosystem): the open data, refreshed daily (CC BY 4.0)
- [Data API](https://builder.registrai.cc/data-api/): free JSON, no key
- MCP server for AI agents: `https://builder.registrai.cc/api/mcp` (MCP Registry: `cc.registrai/arc-data`)

Registrai is independent and not affiliated with Circle or Arc.
